# store-io-core

Shared vocabulary of [store-io](https://github.com/jamesgober/store-io): identities,
durability classes and receipt labels, the error model, device evidence, and the
pure rules that decide a device's durability class and untorn-write unit.

Most users want the [`store-io`](https://crates.io/crates/store-io) crate instead.
