# store-io v0.1.0 &mdash; Scaffold

**The crate name is reserved and the project is open.** This release contains no
public API. store-io follows a research-first plan: every file and I/O method on
every target platform is catalogued and measured, the architecture is planned
file by file and approved, and only then is library code written.

## What is store-io?

The storage I/O layer for Rust databases and storage engines, and the
replacement for [fsys](https://github.com/jamesgober/fsys-rs). It moves caller
bytes between memory and media on Linux, Windows and macOS and proves when they
are durable:

- **Durability classes from evidence.** Each volume is classed as power-safe,
  flush-required, unverified or unsafe from what the device itself reports.
- **Unforgeable receipts.** Typed positions, write tickets and receipts; a
  barrier is never a silent no-op.
- **Fail-stop.** The first failed write or flush poisons the device's barrier
  domain; a flush is never retried.
- **Nothing hidden.** No framing, no repair on open, no timers, no group-commit
  windows, no idle wakeups.

## Breaking changes

None. This is the first release.

## Verification

Run on Windows x86_64, Rust stable 1.95:

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --all-features -- -D warnings
cargo test --workspace --all-features
RUSTDOCFLAGS="-D warnings" cargo doc --workspace --no-deps --all-features
RUSTUP_TOOLCHAIN=1.85 cargo build --workspace --all-features
cargo package --locked
```

The CI matrix (Linux, macOS, Windows x stable, 1.85) runs the same checks plus
`cargo audit` and `cargo deny check`.

## What's next

The research sweep: thirteen tracks covering Linux, Windows and macOS
interfaces, device features, submission engines, filesystem durability
semantics, buffer and space management, small-object commits, crash-testing
tools, deterministic simulation, existing crates and prior art in databases.
Their synthesis chooses the mechanism for every platform, device class and
operation, and feeds the architecture.
